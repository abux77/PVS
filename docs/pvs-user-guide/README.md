# PVS v0.4 interactive user guide

Open [index.html](index.html) in a browser to view the documentation locally. The page is self-contained: it embeds its PVS illustration as SVG, with clickable hotspots for phrase keys, mode keys A–D, and knob controls.

## Publish with GitHub Pages

For a repository site using the `main` branch's `/docs` directory as the publishing source, this guide will be available under `/PVS/pvs-user-guide/` after the pull request is merged and Pages is configured.

The existing repository README and documentation are not changed.
