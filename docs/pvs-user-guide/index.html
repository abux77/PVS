QUICK START02 / 21

Getting Started

Connect the PVS to USB power.

The OLED shows the PVS logo, then the current operating mode and knob values.

Press any of the twelve phrase keys to hear speech.

Use the red knob for Speed and the blue knob for Pitch in Normal Mode.

PLAYBACK03 / 21

Playing Phrases

The twelve phrase keys are 1–9, *, 0 and #.

Each key plays the matching phrase in the selected bank.

Press another phrase key to interrupt speech and play a different phrase.

Press the same key again to restart it.

PERFORMANCE04 / 21

Normal Mode

Normal Mode is the starting point for everyday phrase playback.

BLUE KNOB - Pitch

RED KNOB – Speed

These controls reshape the synthetic voice.

Changes to voice parameters take effect at word boundaries.

PERFORMANCE05 / 21

Voice Mode

Tap A to enter or leave Voice Mode.

BLUE KNOB - Throat

RED KNOB - Mouth

These controls reshape the synthetic voice.

Changes to voice parameters take effect at word boundaries.

PERFORMANCE06 / 21

Sample Mode

Tap B to enter or leave Sample Mode.

BLUE KNOB - Bit Depth (8bit to 1bit)

RED KNOB - Sample Rate (8 to 44.1kHz)

Turning the red knob toward its minimum ADC position selects the highest sample rate.

The selected sample rate persists after leaving this mode.

PERFORMANCE07 / 21

Chromatic Mode

Tap C to enter or leave Chromatic Mode.

The twelve phrase keys replay the last phrase at successive semitones, C through B.

BLUE KNOB - Pitch

RED KNOB - Speed

MEMORY08 / 21

Preset Mode

Tap D to enter or leave Preset Mode.

Tap a phrase key to recall its preset.

Hold a phrase key for at least 2 seconds to store the current settings.

The PVS confirms the action and exits Preset Mode.

MEMORY09 / 21

Phrase Banks

There are 12 phrase banks, each with up to 12 phrases.

Hold D, then press a phrase key to select its bank.

Keys * / 0 / # select banks 10 / 11 / 12.

The OLED briefly displays BANK X / LOADED.

MEMORY10 / 21

Parameter Locks

A phrase can remember its own settings without changing the global voice.

Three lock groups are available:

  • A + phrase: Mouth and Throat
  • B + phrase: Sample Rate and Bit Depth
  • C + phrase: Speed and Pitch
MEMORY11 / 21

Save Parameter Locks

Adjust the desired parameters first.

Hold the corresponding mode key (A, B or C), press a phrase key, then release the phrase key to store that group.

The OLED confirms PARAMETER / LOCKED.

MEMORY12 / 21

Clear Parameter Locks

To clear one lock group, hold its mode key (A, B or C) together with the phrase key for at least 2 seconds.

To clear ALL locks in the currently selected bank, hold D and press B.

Locks are saved separately for each phrase bank.

CONTROLS13 / 21

Soft Takeover

When you change modes or recall a preset, the physical knob position may not match the saved parameter value.

The PVS uses soft takeover to prevent sudden jumps.

Move the knob until it picks up the current value; then adjustments take effect.

FILE MANAGEMENT14 / 21

Usb Edit Mode

Press A + D together

Speech stops and a USB disk named PVS becomes available on your computer.

Edit or copy the text files, then EJECT the PVS drive in your operating system.

The PVS reloads its files and resumes operation after eject.

FILE MANAGEMENT15 / 21

Editing Phrase Files

Open phrases_1.txt through phrases_12.txt with a plain-text editor.

Each bank has up to twelve lines in keypad order:

1, 2, 3, 4, 5, 6, 7, 8, 9, *, 0, #

Start a line with S: for text or P: for SAM phonemes.

Lines starting with # are comments.

FILE MANAGEMENT16 / 21

Phrase File Example

Example contents of phrases_1.txt:

S:HELLO THERE
S:WELCOME TO PVS
P:AY4 AEM AH ROH4BOWLAORD

Keep one phrase per key position.

Make a backup before editing and always eject the PVS USB disk safely.

FILE MANAGEMENT17 / 21

Sam Phonetics

Use S: for ordinary text: the speech reciter converts it to phonemes.

Use P: when you want to specify SAM phonemes directly, including stress and pronunciation.

Example: P:AY4 AEM AH ROH4BOWLAORD

Phonetic spelling is different from ordinary English spelling.

FILE MANAGEMENT18 / 21

Editing Presets

In USB Edit Mode, presets.txt stores one preset per CSV row:

preset,speed,pitch,mouth,throat,sample_rate,bit_depth

Parameter locks are stored separately in locks_1.txt through locks_12.txt.

Prefer the keypad for saving presets and locks during normal use.

FILE MANAGEMENT19 / 21

Startup Configuration

startup_state.txt contains:

bank,preset

It selects the phrase bank and optional preset loaded at startup.

A preset value of 0 disables startup preset recall.

The supplied factory startup file selects bank 3 and preset 1.

MAINTENANCE20 / 21

Firmware Update

Press B + C together to enter Firmware Flash Mode.

The PVS stops playback and opens its bootloader USB drive (RPI-RP2 on Pico).

Copy the correct pvs.uf2 firmware file for your board to that drive.

The PVS restarts automatically.

SUPPORT21 / 21

Troubleshooting

No knob response?

Move the knob until soft takeover engages.

Edited phrases not showing?

Eject the PVS USB drive; changes load after eject.
